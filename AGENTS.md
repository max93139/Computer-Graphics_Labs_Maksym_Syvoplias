# Правила та інструкції для проєкту

## Стиль коду, коментування та вивід у консоль
- **Заборона декоративних розділювачів**: Не додавати у файли коду та у вивід програми (консоль) декоративні елементи, рамки та коментарі/лінії розділювачів на кшталт `# =====================================================================`, `print("=" * 65)`, `print("-" * 65)` тощо.
- Використовувати стандартні, лаконічні та чисті коментарі/документацію (docstrings) та акуратний, мінімалістичний вивід без надлишкових графічних рамок та ліній.
