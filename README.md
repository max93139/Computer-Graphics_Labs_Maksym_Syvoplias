## Відповіді на питання для самоконтролю (з методички)

1. **Що таке конвертація форматів зображень, і для чого вона потрібна?**
   - Це процес перетворення графічних даних з однієї файлової структури в іншу. Потрібна для оптимізації розміру файлу, забезпечення сумісності з пристроями/веб-сайтами, підтримки прозорості або підготовки до друку.

2. **Які популярні формати зображень використовуються для збереження графічних даних, і які їх особливості?**
   -  — стиснення з втратами, ідеальний для фотографій.
   -  — стиснення без втрат, підтримка альфа-каналу (прозорості).
   -  — нестиснений растровий формат, точна передача кольору, великий розмір.
   -  — професійний формат для поліграфії та сканування, висока точність.
   -  — сучасний формат Google для вебу з ефективним стисненням як з втратами, так і без.

3. **Як змінюється розмір файлу зображення при конвертації між різними форматами?**
   - Нестиснені формати (BMP) займають найбільше місця. Стиснення без втрат (PNG) зменшує розмір без шкоди для якості. Стиснення з втратами (JPEG, WebP) дає найменший розмір за рахунок видалення дрібних, непомітних для людського ока деталей.

4. **Що таке зміна розміру зображення, і які алгоритми використовуються для цього?**
   - Це перерахунок кількості пікселів зображення. Використовуються методи інтерполяції: найближчого сусіда (Nearest Neighbor), білінійна (Bilinear), бікубічна (Bicubic) та фільтр Ланцоша (Lanczos).

5. **Чому важливо зберігати співвідношення сторін під час зміни розміру зображення?**
   - Щоб уникнути спотворення геометрії об'єктів (розтягування або сплющування по вертикалі/горизонталі).

6. **Як впливає зменшення розміру зображення на його якість і деталізацію?**
   - Зменшується загальна кількість пікселів, що призводить до втрати дрібних деталей, але зменшує обсяг файлу та прискорює його відображення.

7. **Що таке перетворення кольорів у зображенні, і які завдання воно може вирішувати?**
   - Це модифікація колірних значень окремих пікселів або всього зображення. Використовується для заміни фону, виділення об'єктів, стилізації та сегментації.

8. **Як технічно реалізується заміна певного кольору на інший у зображенні?**
   - Попіксельним перебором: для кожного пікселя перевіряється, чи відповідає його RGB-значення цільовому (з урахуванням порогу похибки tolerance), і у разі збігу записується нове RGB-значення.

9. **Що таке колірний баланс, і які параметри його корекції використовуються в обробці зображень?**
   - Це співвідношення між основними колірними компонентами (R, G, B). Корекція здійснюється зміною інтенсивності окремих каналів (множники factor або адитивні зміщення delta) для усунення небажаних відтінків (наприклад, занадто жовтого або синього освітлення).

10. **Як впливає корекція колірного балансу на сприйняття зображення користувачем?**
    - Робить кольори більш природними (натуральними), підсилює емоційну виразність зображення (теплі/холодні тони) та покращує розбірливість деталей.
