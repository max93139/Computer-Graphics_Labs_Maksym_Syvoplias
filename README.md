# Лабораторна робота №1: Комп'ютерна графіка та візуалізація

## Тема
**Розробка програми для обробки зображень: конвертація форматів, зміна розміру, перетворення кольорів та корекція колірного балансу.**

## Мета роботи
- Ознайомитися з основними принципами обробки цифрових зображень.
- Розробити консольну програму на Python з **власними, розписаними вручну алгоритмами**:
  1. **Конвертація форматів**:
     - Конвертація між форматами JPEG, PNG, BMP, TIFF, WebP (поодиноко та пакетно для декількох зображень).
     - Порівняння розмірів файлів до та після обробки (в байтах, КБ та у відсотках).
  2. **Зміна розміру зображень**:
     - Власний алгоритм **інтерполяції найближчого сусіда (Nearest Neighbor)**.
     - Власний алгоритм **білінійної інтерполяції (Bilinear Interpolation)**.
     - Зміна розміру одного або декількох зображень за один запуск (пакетна обробка).
     - Пропорційна зміна за шириною або висотою (`H_new = H_orig * (W_new / W_orig)`), масштабування у відсотках та точні розміри.
  3. **Перетворення кольорів**:
     - Попіксельна заміна кольорів $(R_1, G_1, B_1) \to (R_2, G_2, B_2)$ з настроюваним порогом толерантності.
  4. **Корекція колірного балансу**:
     - Ручне налаштування яскравості RGB-каналів за допомогою множників та адитивних зміщень.
     - Автоматичний баланс кольорів за формулою з методичних вказівок (зсув середніх значень до 128).

## Детальний опис алгоритмів та формул

### 1. Конвертація форматів та розрахунок зміни розміру (`image_converter.py`)
- Завантаження зображення та збереження у цільовий формат.
- Обчислення зміни розміру у байтах, кілобайтах та у відсотках:
  $$\Delta \% = \frac{\text{size}_{final} - \text{size}_{initial}}{\text{size}_{initial}} \times 100\%$$

### 2. Алгоритми зміни розміру (`resize_nearest_neighbor`, `resize_bilinear`)
- **Найближчий сусід (Nearest Neighbor)**:
  $$x_{orig} = \lfloor x_{new} \cdot \frac{W_{orig}}{W_{new}} \rfloor, \quad y_{orig} = \lfloor y_{new} \cdot \frac{H_{orig}}{H_{new}} \rfloor$$
- **Білінійна інтерполяція (Bilinear)**:
  Для кожної неперервної точки обчислюються ваги $dx, dy$ від 4 сусідніх цілочисельних координат:
  $$C(x, y) = (1-dx)(1-dy)C_{11} + dx(1-dy)C_{21} + (1-dx)dy C_{12} + dx\,dy\,C_{22}$$

### 3. Попіксельна заміна кольорів (`replace_pixels_color`)
- Для кожного пікселя $(R, G, B)$ перевіряється умова:
  $$|R - R_{target}| \le \text{tolerance} \quad \text{та} \quad |G - G_{target}| \le \text{tolerance} \quad \text{та} \quad |B - B_{target}| \le \text{tolerance}$$
- У разі виконання умови піксель замінюється на $(R_{new}, G_{new}, B_{new})$.

### 4. Корекція колірного балансу (`apply_color_balance`, `apply_auto_color_balance`)
- **Ручна корекція**:
  $$C_{new} = \text{clamp}(\lfloor C_{old} \times \text{factor} + \text{delta} \rfloor, 0, 255)$$
- **Автоматичний баланс (за методичкою)**:
  1. Обчислюються середні значення каналів $\mu_R, \mu_G, \mu_B$.
  2. Обчислюються величини зсуву: $\Delta R = 128 - \mu_R, \; \Delta G = 128 - \mu_G, \; \Delta B = 128 - \mu_B$.
  3. Для кожного пікселя: $C_{new} = \text{clamp}(C_{old} + \Delta C, 0, 255)$.

## Відповіді на питання для самоконтролю з методички

1. **Що таке конвертація форматів зображень, і для чого вона потрібна?**
   - Це процес перетворення графічних даних з однієї файлової структури в іншу для оптимізації обсягу файлу, передачі мережею, забезпечення сумісності з веб-браузерами та графічними редакторами або підтримки прозорості.

2. **Які популярні формати зображень використовуються для збереження графічних даних, і які їх особливості?**
   - `JPEG` — алгоритм стиснення з втратами (DCT), малий розмір, оптимізований під фотографії.
   - `PNG` — алгоритм Deflate без втрат, підтримка альфа-каналу (прозорості).
   - `BMP` — растровий нестиснений формат (або RLE), містить точні попіксельні дані, великий розмір.
   - `TIFF` — професійний формат поліграфії та медицини, висока точність і гнучкість.
   - `WebP` — сучасний формат з високим коефіцієнтом стиснення як з втратами, так і без.

3. **Як змінюється розмір файлу зображення при конвертації між різними форматами?**
   - Нестиснений BMP займає найбільше місця ($W \times H \times 3$ байти + заголовки). PNG стискає дані без втрати жодного пікселя. JPEG та WebP суттєво зменшують розмір за рахунок усунення надлишкової високочастотної колірної інформації.

4. **Що таке зміна розміру зображення, і які алгоритми використовуються для цього?**
   - Це передискретизація (ресемплінг) піксельної сітки. Основні алгоритми: найближчого сусіда (Nearest Neighbor), білінійна інтерполяція (Bilinear), бікубічна (Bicubic) та фільтр Ланцоша (Lanczos).

5. **Чому важливо зберігати співвідношення сторін під час зміни розміру зображення?**
   - Щоб не спотворювати геометрію зображених об'єктів (уникнути неприродного розтягування або стискання вздовж однієї з осей).

6. **Як впливає зменшення розміру зображення на його якість і деталізацію?**
   - Зменшується загальна кількість дискретних відліків (пікселів), через що дрібні високочастотні деталі усереднюються або втрачаються, проте файл стає значно легшим.

7. **Що таке перетворення кольорів у зображенні, і які завдання воно може вирішувати?**
   - Це цілеспрямована модифікація значень колірних каналів пікселів. Вирішує завдання хромакею (заміни фону), сегментації об'єктів, стилізації та підготовки масок.

8. **Як технічно реалізується заміна певного кольору на інший у зображенні?**
   - Попіксельним скануванням матриці зображення: колір кожного пікселя порівнюється з цільовим $(R_t, G_t, B_t)$ з урахуванням допустимого околу (tolerance), і при збігу пікселю присвоюється новий колір.

9. **Що таке колірний баланс, і які параметри його корекції використовуються в обробці зображень?**
   - Це взаємне співвідношення інтенсивностей базових колірних каналів (R, G, B). Корекція виконується масштабуванням каналів (множники gain/factor) та зсувом (offset/delta) для відновлення природних кольорів нейтральних тонів.

10. **Як впливає корекція колірного балансу на сприйняття зображення користувачем?**
    - Усуває колірні спотворення (паразитні відтінки від ламп розжарювання або тіні), робить зображення візуально приємним, природним та підвищує контрастність ключових деталей.
