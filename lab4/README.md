# Лабораторна робота №4
**Дисципліна:** Комп'ютерна графіка та візуалізація  
**Тема:** Обробка та аналіз кольорових зображень: відображення, аналіз яскравості, гістограми та зміна кольорових характеристик.

## Огляд структури проєкту

Проєкт містить виключно завдання Лабораторної роботи №4, розбиті за модульним принципом:

- `lab4_manual_algorithms.py` — чисті низькорівневі попіксельні алгоритми:
  - `calculate_pixel_brightness` — обчислення яскравості пікселя за формулою люмінансу:
    $$Y = 0.299 \cdot R + 0.587 \cdot G + 0.114 \cdot B$$
  - `calculate_brightness_matrix` — формування двовимірної матриці яскравості $H \times W$.
  - `build_histogram` — статистичний підрахунок частот для рівнів інтенсивності 0..255.
  - `to_grayscale` — перетворення повнокольорового зображення у відтінки сірого ($R = G = B = Y$).
  - `binarize` — порогова бінаризація зображення ($Y > P \implies 255$, інакше $0$).
  - `to_negative` — створення фотографічного негативу ($255 - C$).
- `lab4_operations.py` — операції читання/запису зображень (Pillow), експорт матриці яскравості у текстовий файл та побудова графіків гістограм через `matplotlib`.
- `main.py` — консольне меню без декоративного шуму.
- `samples/` — тестові вхідні зображення.
- `output/` — результати обробки (матриця яскравості, гістограми, бінаризоване зображення, відтінки сірого, негатив).

## Завдання для виконання

1. Виведення первинного кольорового зображення на екран.
2. Виведення на екран матриці значень яскравості зображення.
3. Побудова гістограми яскравості кольорового зображення.
4. Зміна кольоровості:
   - бінаризація (перехід до чорно-білого);
   - перехід до відтінків сірого;
   - негатив;
   - побудова гістограми зображення в градаціях сірого.

## Запуск програми

cd lab4
